How it works

  • Tap an answer — you see Right or Wrong instantly, with the correct answer and a short explanation.
  • No Next button — the next question appears automatically after a few seconds.
  • Beat the clock — 30 seconds per question. If time runs out, the question is marked wrong.
  • A fresh set every run — 50 questions are picked at random from the bank each time, with question and answer order shuffled.
  • Review at the end — check every question again with the correct answers.
